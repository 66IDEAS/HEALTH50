## Description

```
Health50 exporte les données de santé de votre iPhone sous forme de simples fichiers JSON, pour les utiliser avec les outils de votre choix : un tableur, un script ou un assistant IA.

ENREGISTRER UNE COPIE
Touchez « Enregistrer dans Fichiers… » et choisissez les 30 derniers jours, les 12 derniers mois ou tout l’historique. Health50 écrit un fichier JSON à l’emplacement que vous choisissez.

RESTER À JOUR
Activez l’export automatique et Health50 tient à jour un dossier de votre propre Google Drive : un fichier par mois, mis à jour en arrière-plan dès que quelque chose a changé.

VOUS DÉCIDEZ DE CE QUI EST EXPORTÉ
iOS vous demande quelles données de santé Health50 peut lire. Partagez-les toutes ou seulement une partie. Health50 n’exporte que ce que vous autorisez, et se contente de lire. Vos données de santé ne sont jamais modifiées.

CONFIDENTIEL PAR CONCEPTION
• Aucun compte Health50 et aucun serveur Health50.
• Ni analyse, ni publicité, ni suivi.
• Les données vont directement de votre iPhone vers l’emplacement que vous choisissez.
• Dans Google Drive, Health50 ne peut utiliser que les fichiers et dossiers qu’il a lui-même créés.

UN FORMAT LISIBLE
Les fichiers sont du simple JSON avec des noms clairs, les identifiants d’Apple pour les types de données et une unité pour chaque valeur. Ils couvrent l’activité, le cœur, le sommeil, les exercices avec leurs parcours, les mensurations, la nutrition, la pleine conscience, les ECG et plus encore : plus de 190 types de données. Les dossiers médicaux ne sont pas inclus.

GRATUIT ET OPEN SOURCE
Health50 est gratuit, sans achats. Son code source, la description du format de fichier et sa politique de confidentialité sont publics :
github.com/66IDEAS/HEALTH50

Health50 n’est pas un dispositif médical et ne donne aucun conseil médical. Il lit les données de l’app Santé de votre iPhone. Google Drive est une marque de Google LLC.
```
