## Description

```
Health50 esporta i dati sanitari del tuo iPhone come semplici file JSON, così puoi usarli con gli strumenti che preferisci: un foglio di calcolo, uno script o un assistente IA.

SALVA UNA COPIA
Tocca “Salva su File…” e scegli gli ultimi 30 giorni, gli ultimi 12 mesi o tutta la cronologia. Health50 scrive un file JSON nella posizione che scegli.

TIENILA AGGIORNATA
Attiva l’esportazione automatica e Health50 mantiene aggiornata una cartella del tuo Google Drive: un file al mese, aggiornato in background quando qualcosa cambia.

DECIDI TU COSA ESPORTARE
iOS ti chiede quali dati sanitari Health50 può leggere. Condividili tutti o solo in parte. Health50 esporta solo ciò che consenti e si limita a leggere. Non modifica mai i tuoi dati sanitari.

PRIVATO FIN DALLA PROGETTAZIONE
• Nessun account Health50 e nessun server Health50.
• Niente analisi, pubblicità o tracciamento.
• I dati passano direttamente dal tuo iPhone alla destinazione che scegli.
• In Google Drive, Health50 può usare solo i file e le cartelle che ha creato.

UN FORMATO CHE PUOI LEGGERE
I file sono semplice JSON con nomi chiari, gli identificatori di Apple per i tipi di dati e un’unità per ogni valore. Comprendono attività, cuore, sonno, allenamenti con percorsi, misure corporee, alimentazione, mindfulness, ECG e altro: oltre 190 tipi di dati. Le cartelle cliniche non sono incluse.

GRATIS E OPEN SOURCE
Health50 è gratuito e senza acquisti. Il codice sorgente, la descrizione del formato dei file e l’informativa sulla privacy sono pubblici:
github.com/66IDEAS/HEALTH50

Health50 non è un dispositivo medico e non fornisce consigli medici. Legge i dati dall’app Salute del tuo iPhone. Google Drive è un marchio di Google LLC.
```
