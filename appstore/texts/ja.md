## Description

```
Health50は、iPhoneのヘルスケアデータをシンプルなJSONファイルとして書き出します。表計算ソフト、スクリプト、AIアシスタントなど、お好みのツールで利用できます。

コピーを保存
「“ファイル”に保存…」をタップして、過去30日間、過去12か月、またはすべての履歴を選びます。Health50は、選択した場所にJSONファイルを1つ書き出します。

常に最新に
自動書き出しをオンにすると、Health50が自分のGoogle ドライブのフォルダを最新の状態に保ちます。月ごとに1つのファイルを保存し、変更があるとバックグラウンドで更新します。

書き出す内容は自分で決める
Health50が読み取れるヘルスケアデータは、iOSが確認します。すべて、または一部だけを共有できます。Health50は許可されたデータのみを書き出し、読み取るだけです。ヘルスケアデータを変更することはありません。

プライバシーを最優先に設計
• Health50のアカウントもサーバもありません。
• 解析、広告、トラッキングはありません。
• データはiPhoneから、選択した保存先へ直接送られます。
• Google ドライブでは、Health50が自ら作成したファイルとフォルダのみを扱えます。

読みやすいフォーマット
ファイルはシンプルなJSONで、わかりやすい名前、Appleのデータタイプ識別子、すべての値の単位を含みます。アクティビティ、心臓、睡眠、経路付きのワークアウト、身体測定値、栄養、マインドフルネス、心電図など、190種類以上のデータタイプに対応します。臨床記録は含まれません。

無料・オープンソース
Health50は無料で、App内課金はありません。ソースコード、ファイルフォーマットの説明、プライバシーポリシーは公開されています：
github.com/66IDEAS/HEALTH50

Health50は医療機器ではなく、医学的な助言は行いません。iPhoneの「ヘルスケア」Appからデータを読み取ります。Google ドライブはGoogle LLCの商標です。
```
